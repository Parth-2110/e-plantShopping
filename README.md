# e-plantShopping

## Project Overview
**e-plantShopping** is a React-based e-commerce application for an online plant nursery called Paradise Nursery.

The application allows users to explore plants, browse products, and manage their shopping cart.

## Features
- Browse available plants.
- View product information.
- Add plants to the shopping cart.
- View cart items.
- Navigate between the home page, plants page, and cart.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the application:

```bash
npm run preview
```

Follow the lab instructions to open the application in your browser.
